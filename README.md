# Tripleten web_project_homeland

📱 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de aprimorar e aplicar conhecimentos em responsividade no desenvolvimento web.

A proposta consiste em adaptar o layout de um site para que ele funcione corretamente em diferentes tamanhos de tela, oferecendo uma boa experiência de navegação tanto em computadores, quanto em tablets e dispositivos móveis.

Durante o desenvolvimento, foram realizados ajustes nos elementos da página para evitar problemas como conteúdos desaparecendo, transbordando da tela ou ficando desalinhados em resoluções menores.

⚙️ Funcionalidades

Layout adaptado para diferentes resoluções de tela;
Compatibilidade com computadores, tablets e celulares;
Ajuste e reorganização dos elementos conforme o tamanho da tela;
Melhor aproveitamento do espaço disponível;
Navegação e visualização mais adequadas em dispositivos móveis.

🛠️ Tecnologias e técnicas utilizadas

Para o desenvolvimento deste projeto foram utilizadas as seguintes tecnologias:

HTML5 — utilizado para estruturar o conteúdo da página;
CSS3 — utilizado para estilização e organização visual dos elementos.

Também foram aplicadas técnicas de design responsivo, como:

Media Queries, para criar adaptações específicas para diferentes tamanhos de tela;
Flexbox, para organizar e alinhar os elementos de forma flexível;
Unidades relativas, como %, vw, vh e rem, quando necessário;
Ajustes de largura, espaçamento, alinhamento e posicionamento dos elementos;
Criação de breakpoints para adaptar o layout entre desktop, tablet e celular.
